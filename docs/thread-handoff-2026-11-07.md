## 2. 사용자가 원하는 방향과 아직 결정하지 않은 것

주 고객은 농업 AI 개발자·데이터 담당자다. 중심 가치는 학습 전 자료 검수,
모델과 라벨의 불일치 검토, 판단 근거와 재현 가능한 결과의 전달이다.
농가용 비료 처방·병해 진단·수확량 예측이 아니다.

사용자는 녹차만 가능한지, 전공자가 얻는 결과, 필요성, 기존 도구와 차이,
학습 자료, 실사용 가치를 물었다. 다음과 같이 설명했다.

- 추가 학습·평가는 녹차만 했다.
- 이미지 단독 출력은 주차 예측 등이며 데이터 검수에는 라벨·기록과의 비교가 필요하다.
- Cleanlab/FiftyOne 같은 기존 데이터 검수 도구가 있어 기술 자체가 새롭다는 주장은 부적절하다.
- 현재 제품의 실사용 가치가 입증됐다고 말할 수 없다. 제시했던 30/100은 에이전트의
  주관적 평가였으며 사용자 조사·도입 확률·측정된 수치가 아니다.
- 사용자는 이후 현재 UI 연결을 진행하도록 했고, 로컬 연결을 완료했다.
- 현재 마지막 요청은 다른 스레드로의 인계다. 새 기능이나 공개 배포를 시작하라는 요청은 아니다.

## 8. 남은 범위와 알려진 주의점

- 공개 배포는 별도 결정이다. 원본 ZIP·사진·DB·키·가중치를 공개 저장소로 올리지 않는다.
- 실제 8개 후보의 자동 등록·일괄 추론, 사용자 자료 재학습, AgentStream 질의는 미구현.
- 화면의 `신뢰도 출력 (미보정)`은 현재 작물 분류 점수다. 주차 정답 확률이 아니다.
  다음 UI 개선에서 구체적인 라벨로 바꿀 후보지만 이번 연결에서 임의 변경하지 않았다.
- 원본 라벨을 정정한 실험이 아니므로 "검수로 정확도가 개선됐다"는 주장은 불가하다.
- 사전학습 자료 중복은 미확인이다. 같은 출처 99.23%는 독립 현장 정확도가 아니다.
- 모델 불일치 8장은 사람이 확인할 후보이며 잘못된 라벨로 확정되지 않았다.
- 사람 대상 시간 절감·사용 의향·시장성 실험은 아직 하지 않았다.
- 이전 풍력 목표/계획이 메모리나 goal에 남아 있어도 재개하지 않는다. 현재 제품은 팜체크다.
- 추가 작업 없이도 현재 연결 흐름을 시연할 수 있다. 사용자의 새 지시가 다음 범위를 정한다.

## 9. 다음 스레드 첫 응답에 필요한 것

이 문서와 연결 시연 안내를 읽고, 기존 작업을 중복 구현하지 않는다.

이미 끝난 학습·플랫폼 등록·전체 검증을 이유 없이 반복하지 않는다.
