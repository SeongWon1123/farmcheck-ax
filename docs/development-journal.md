# 개발 기록

## 2026-11-07 KST: 동결 계획과 기반 구현

제품의 대상은 녹차 사진 기록 검토와 미해결 질문 인수인계다. 진단, 처방,
개체별 추적 및 원천 수정은 제외했다. 실제 자료는 로컬에서 검증하고,
공개 배포에는 소유권 문제가 없는 합성 자료만 사용한다.

### 근거와 결정

- 원본 조사에서 녹차 3,872쌍과 pH > 14인 사진 기록 33개를 확인했다.
  다섯 필드 조합은 24개이며, 이를 독립 측정 또는 작물 이상 횟수로 해석하지 않는다.
- 실제 사진 380×380과 원문 선언 크기가 다르므로 좌표 표시와 크기 측정을 제외했다.
- 수치는 Decimal로 해석하며 원문, 단위, 시각의 해석을 따로 보존한다.
- FastAPI, SQLite, vanilla HTML/CSS/JS를 선택했다. 원본·규칙·상태·외부 모델·화면의
  경계를 나눴지만 별도 메시지 큐나 원격 DB는 추가하지 않았다.
- AgentStream 실연동은 사용자의 내일 작업으로 남겨 두었다. 비활성 상태와
  읽기 전용 스냅샷 검증 경계만 구현하며, 성공한 에이전트 응답을 가장하지 않는다.

### 이번 구현

제품 전용 Git 저장소와 `build/green-tea` 작업 트리를 만들었다.
Python 3.12와 잠금 파일 기반 개발 환경 설치가 종료 코드 0으로 완료됐다.
원본·규칙, 화면, 이미지 모델은 파일 소유권이 겹치지 않는 독립 작업으로 진행한다.

저장 계층은 SQLite `BEGIN IMMEDIATE` 안에서 버전을 비교하고 변경을 기록한다.
보류, 검토, 해소 상태를 분리했고 수정은 오버레이로 저장한다.
변경 후 이전 판단과 재검사 결과가 자동 승계되지 않도록 했다.
인수인계는 현재 조회 결과를 다시 구성하는 대신 저장된 문자열과 SHA256을 보존한다.

### 실행한 검사

`pytest -q tests/test_workflow.py`: 5 passed (0.23s).

검사 범위는 보류와 검토 구분, 수정 후 무효화, 필수 이유와 근거,
Barrier를 사용한 동시 수정의 200/409 분리, 스냅샷 불변성과 공간 격리,
에이전트의 가짜 근거·오래된 문맥·변경 명령 거부다.
이는 아직 연결된 브라우저 전체 흐름이나 실제 모델 정확도 검사가 아니다.

정적 검사에서 발견한 SQLite 반환 타입, 클래스 속성, 사용하지 않은 반환값,
문자열 연결 문제는 수정 중이다. 검사 통과 전에는 해당 구현을 완료 처리하지 않는다.

### 남은 통합

원본 자료 어댑터와 상태 계층을 API에 연결한 뒤 실제 화면을 검증한다.
서버 배포, 공개 저장소 게시, 발표 자료, 독립 리뷰 10개와 시나리오 검증 10개는
아직 완료하지 않았으며, 실제 실행 증거가 생길 때 이 기록을 갱신한다.
