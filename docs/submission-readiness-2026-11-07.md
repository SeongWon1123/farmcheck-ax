## 4. 발표에서 유지할 구분

- 추가 학습·평가 범위는 녹차다.
- 모델과 원본 주차의 불일치는 검수 후보이지 라벨 오류 확정이 아니다.
- 작물 분류 점수를 주차 정답 확률로 설명하지 않는다.
- 한 장 개선과 같은 출처 시험 점수를 독립 현장 성능으로 설명하지 않는다.
- 검토 기록이 재학습으로 연결되거나 실제 업무 시간이 줄었다고 주장하지 않는다.
- 공개 웹사이트는 서버에서 동작한다. 로컬 PC 대신 팀 개발 서버가
  웹앱을 계속 실행하고, 별도의 AIStream 서버가 모델 추론을 수행한다.
- 대회 종료 후 제공 자원과 URL은 회수되므로 영구 운영 주소가 아니다.
