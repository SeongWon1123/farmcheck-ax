**해석 제한:** 같은 400장을 보고 임계값을 선택했으므로 0/400은 보정 표본 안의 수치다. 사람의 정상/불량 품질 정답도 없다. 독립 사진이나 현장에서 오경보 1% 이하를 보장한 결과가 아니다. 변형 검출률은 명시된 인공 변형 강도에 한정된다. 0/80, 20/20도 일반적인 비작물 검출이나 현장 정확도 증명이 아니다.

## 3. 추가 실제 추론 7건

동일한 원격 `SV-9e5ca608/predict`를 호출했다. 모두 HTTP 200이었다. 아래 confidence는 API가 반환한 모델 점수이며 정답 확률이 아니다.

| 입력 | 예측 작물 | 작물 점수 | 예측 주차 | 주차 점수 |
|---|---|---:|---|---:|
| 제공 녹차 사진 `05_00.jpg` | 녹차 | 1.000000 | 7주차 | 1.000000 |
| 제공 밀순 사진 `01_00.jpg` | 밀순 | 1.000000 | 0주차 | 1.000000 |
| 녹차 변형의 원본 `tea-00.png` | 녹차 | 1.000000 | 8주차 | 1.000000 |
| 위 원본의 Gaussian blur 5 JPEG | 새싹인삼_개량종 | 0.682859 | 5주차 | 0.933002 |
| 식물 없는 균일 회색 PNG | 밀순 | 0.767786 | 0주차 | 0.752086 |
| 식물 없는 균일 검정 PNG | 밀순 | 0.858964 | 1주차 | 0.593247 |
| 식물 없는 균일 흰색 PNG | 밀순 | 0.916212 | 0주차 | 0.996260 |

균일 제어 이미지는 380×380 RGB, 회색 #808080 / 검정 #000000 / 흰색 #ffffff이다. 외부 사진을 수집하지 않았다.

**핵심:** 다른 작물을 올렸을 때 그 작물로 분류하는 것은 9종 분류기의 정상 기능이다. 반면 빈 사진에도 작물과 주차를 반환하며, 매우 높은 주차 점수도 나온다. 따라서 분류 응답 성공이나 높은 점수는 입력 사진의 유효성 보증이 아니다. 흐림 때문에 녹차가 다른 작물로 바뀌기도 하므로 비녹차 예측을 실제 작물의 확정 판정으로 쓰면 안 된다.

원시 추가 응답: `artifacts/private/quality-independent-audit/model-probes.json`.

## 4. 현재 검사 코드와 연결 상태

- 기존 작업이 만든 새 파일: `src/farmcheck/static/quality.js`.
- 별도 about:blank Chrome 탭에서 해당 실제 파일을 실행하고 원본·흐림·균일 제어 이미지에 `measure`와 `assess`를 적용했다. 탭은 검증 후 닫았다.
- 원본 녹차 두 사진에는 품질·작물 경고가 없었다. 흐린 녹차에는 BLURRY와 CROP_NOT_TEA가 나왔다. 균일 회색·검정·흰색은 모두 BLURRY와 LOW_CONTRAST가 나왔고 검정은 TOO_DARK, 흰색은 TOO_BRIGHT도 나왔다.
- 밀순 원본에도 선명도·대비 경고가 나왔다. 이 기준은 녹차로 보정되었고 다른 작물 품질로 일반화된 검증은 아니다. 사람 품질 정답 없이 이 경고를 실제 불량 확정으로 세지 않는다.
- Chrome 결과: `artifacts/private/quality-independent-audit/browser-quality-checks.json`.
- 확인 당시 로컬 `index.html`은 quality.js를 로드하지 않고 app.js에도 FarmQuality 사용이 없었다. **새 코드와 평가가 존재하는 것과 실제 제품 UI에 연결된 것은 다르다.** 공개 앱에 경고가 배포되었다고 주장하지 않는다.
- `service.py`는 모델 상태 available을 상세 응답에서 ok로 변환한다. 기존 문서의 detail.model 상태 변환 예시가 이 계약과 맞음을 확인했다.

### 연결 시 권고

1. 사진 품질 경고를 먼저 보여 주고, 화질이 나쁘면 모델의 작물·주차 판단 근거가 약하다고 표시한다.
2. 비녹차 결과는 '녹차 아님 확정'이 아니라 '모델 예측 작물이 자료와 다름, 사진·기록 확인'으로 표시한다.
3. 다른 작물의 주차를 녹차 주차처럼 채택하거나 비교하지 않는다. 원문 자동 수정·판정 자동 완료는 하지 않는다.
4. 경고가 없다는 이유로 사진이 식물/녹차/정상임을 인증하지 않는다. 이 코드는 일반적인 비작물·분포외 입력 검출기가 아니다.
5. 모델 점수 0.8은 시연용 검토 경계이며 검증된 정답 확률 경계가 아니다.
6. 독립 검증에서는 원본별 변형을 같은 분할에 묶고, 정상 품질을 별도로 확인한 미사용 표본에서 전체 경고 합집합의 오경보율을 잰다. 새 외부 데이터 수집은 대회 제한을 따른다.

## 5. AgentStream 확인

별도 읽기 전용 계정·코드 점검 결과:

- 인증된 조직은 AX 해커톤 12팀이다.
- 현재 발급된 API 키가 없고, 챗봇 0개·등록 모델 0개로 확인됐다. 작업공간에서도 사용 가능한 AgentStream 키 설정을 찾지 못했다.
- 현재 앱의 agent 경계는 disabled_by_owner이고 질의 API는 503 경로다.
- 문서화된 외부 API base는 `https://api-gateway.jntp-ax.or.kr/agentstream`이다. 텍스트 메시지 계약은 `POST /open/v1/chat-sessions/{session_id}/messages`, JSON message와 X-API-Key 인증이다.
- 사진 메시지용 필드·multipart·첨부 엔드포인트는 확인되지 않았다. 지식베이스 PDF 업로드 지원은 사진 대화 지원 증거가 아니다.
- 기존 키와 챗봇이 없어 텍스트 설명 시험도 실행하지 못했다. 새 키나 챗봇을 만들지는 않았다.

필요한 것은 조직 대표의 API 키 발급, 사용 가능한 채팅 모델, 생성·공개된 챗봇 ID, 해당 챗봇의 CHAT_INVOKE 권한 매핑, 서버 측 키 보관, 세션 생성 계약이다. 사진 직접 입력은 추가로 실제 비전 모델과 이미지 요청 스키마의 확인이 필요하다. 텍스트만 지원해도 사진 지표·규칙·모델 결과를 전달해 경고를 설명하는 방식은 설계 가능하지만 아직 실연동 결과는 없다.
