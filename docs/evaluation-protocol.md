# 3조건 사용성 평가 계획 (수동 / 규칙 / 에이전트)

이 문서는 **아직 하지 않은 실험의 계획서** 입니다. 결과, 참가자 의견, 효과 크기는 하나도 들어 있지 않습니다.
실험을 마치면 결과는 별도 문서에 적고, 이 계획서는 바꾸지 않습니다. 바꿔야 하면 실험 전에 날짜와 이유를 남깁니다.

## 1. 질문

같은 녹차 기록 묶음을 처리할 때, 도움 방식이 다르면 다음이 달라지는가?

- Q1. 확인해야 할 기록을 빠뜨리는 비율
- Q2. 인수인계에 미해결 질문이 빠짐없이 실리는 비율
- Q3. `검토함` 과 `해소` 를 혼동하는 실수
- Q4. 한 세트를 끝내는 데 걸린 시간과 체감 부담

인과 주장의 범위는 이 과제 세트와 이 참가자로 한정합니다. 현장 수확, 작물 건강, 진단 정확도는 재지 않습니다.

## 2. 조건

| 조건 | 참가자가 받는 도움 | 상태 |
| --- | --- | --- |
| A. 수동 | 기록 목록, 원문, 사진, 필터. 후보 표시 없음 | 구현됨 [관측] |
| B. 규칙 | A + 규칙 후보, 같은 환경 묶음, 비교 기록, 제안 다음 조치 | 구현됨 [관측] |
| C. 에이전트 | B + AgentStream 읽기 전용 질의 응답 | 실연동 전 [계획] |

C는 실연동과 출력 검증기(알 수 없는 ID, 근거 참조, 변경 필드, 오래된 스냅샷 거부)가 실제로 동작하는 것을 확인한 뒤에만 엽니다. 확인 전에 C를 흉내 낸 응답을 쓰지 않습니다.

## 3. 참가자

- 대상: 재배 기록을 다뤄 본 사람, 또는 기록 검토 업무 경험자. 모집 경로와 인원은 실험 전에 확정합니다.
- 최소 계획: 조건별 비교가 가능하도록 참가자 내 설계, 1인당 3세트.
- 사전 동의, 언제든 중단 가능, 개인 식별 정보는 수집하지 않고 참가자 번호만 씁니다.
- 브라우저 자동화나 개발자 본인의 조작은 참가자 결과로 세지 않습니다.

## 4. 과제 세트

- 합성 기록으로 만든 동등 난이도 세트 3개(S1, S2, S3). 실제 사진은 쓰지 않습니다.
- 각 세트에 정답지를 미리 고정합니다: 확인 필요 기록, 묶음 구조, 보류가 맞는 기록, 수정 후 재검사가 필요한 기록.
- 세트마다 넣는 장면 [주입]: pH 후보와 공유 환경 묶음, 주차 불일치, 모델 실패, 보류 기록, 수정과 재검사, 시간대 미확인 시각 차이.
- 정답지는 입력 설계에서 나오며, 시스템 출력에서 거꾸로 만들지 않습니다.

## 5. 배정

- 조건 순서와 세트 짝을 라틴 방격으로 돌려 순서 효과를 나눕니다.
- 배정표는 실험 전에 만들어 해시를 남깁니다.

## 6. 측정

| 지표 | 정의 | 출처 |
| --- | --- | --- |
| 누락률 | 정답지의 확인 필요 기록 중 아무 판단 없이 넘긴 비율 | 서버 감사 이벤트 |
| 질문 전달률 | 정답지 미해결 질문 중 스냅샷에 실린 비율 | 스냅샷 바이트 |
| 상태 혼동 | 근거 없이 해소하려 한 시도, 검토함을 해소로 설명한 경우 | 감사 이벤트 + 사후 질문 |
| 소요 시간 | 세트 시작부터 스냅샷 생성까지 | 서버 타임스탬프 |
| 체감 부담 | NASA-TLX 간이형 | 설문 |
| 신뢰 보정 | 모델·에이전트 출력을 근거 없이 채택한 횟수 | 감사 이벤트 |

## 7. 분석

- 사전에 정한 지표만 1차로 보고합니다. 나머지는 탐색으로 표시합니다.
- 인원이 적으면 효과 크기와 구간만 적고 유의성 주장은 하지 않습니다.
- 실패한 세션, 중단, 기술 오류는 지우지 않고 따로 집계합니다.

## 8. 위험과 대응

| 위험 | 대응 |
| --- | --- |
| 에이전트가 시간 안에 연결되지 않음 | A/B 2조건으로 진행하고 C는 미실시로 적음 |
| 학습 효과 | 라틴 방격, 세트별 동등 설계 |
| 합성 데이터라 현실과 다름 | 결론 범위를 과제 세트로 제한 |
| 개발자가 진행자 | 진행 대본 고정, 도움 발언 기록 |

## 9. 지금 말할 수 있는 것과 없는 것

- 말할 수 있음 [관측]: 수동과 규칙 경로가 구현되어 있고, 기존 모델 API에 5장을 보내 모두 HTTP 200을 받았습니다(`docs/model-smoke.md`).
- 말할 수 없음: 어떤 조건이 더 낫다는 것, 모델 정확도, 에이전트 성능, 현장 효과.
