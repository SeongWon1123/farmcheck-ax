# 녹차 주차 모델 첫 전이학습 결과

2026년 11월 7일 실행한 **같은 출처 자료의 제한적 진단 실험**이다.
농장 현장 성능, 독립적인 정확도, 데이터 검수 서비스의 효과를 입증한 결과는 아니다.

## 무엇을 실제로 했나

AIStream의 기존 농장 모델 버전 1에서 녹차 전용 가중치를 재사용했다.
311개 배열을 빠짐없이 옮기고 독립 TensorFlow 구현과 CPU·B200 출력 일치를
검증한 뒤, 특징 추출기는 고정하고 14개 주차 출력층만 실제로 학습했다.
새 모델을 처음부터 학습하거나 ImageNet 가중치로 바꿔치기하지 않았다.

GPU는 팀 서버의 NVIDIA B200 MIG 1g.45gb다.
실행은 01:58:17~01:58:38 UTC, 즉 **학습·평가·저장까지 21초**였다.
환경 설치·자료 전송·코드 검증·플랫폼 배포 시간은 포함하지 않는다.
6개 epoch를 실행했고, 검증 macro-F1 및 주차 오차 기준으로 첫 epoch를 선택했다.
검증 결과가 더 좋아지지 않아 조기 종료했다.

| 구분 | 사진 수 |
| --- | ---: |
| 학습 | 1,971 |
| 검증 | 805 |
| 시험 | 1,033 |
| 별도 보관: 학습·평가 제외 | 63 |

촬영일은 분할 사이에 겹치지 않는다. 평가 주차는 1·3·4·7·8·12·13이다.
사진 원본과 제공 라벨은 수정하지 않았다.

## 제공 라벨 기준 시험 결과

| 지표 | 기존 모델 | 추가 학습 모델 | 최빈 주차만 예측 |
| --- | ---: | ---: | ---: |
| 일치한 사진 | 1,024 / 1,033 | 1,025 / 1,033 | 300 / 1,033 |
| 일치율 | 99.13% | 99.23% | 29.04% |
| Macro-F1 | 0.9445 | 0.9456 | 0.0643 |
| Balanced accuracy | 0.9377 | 0.9398 | 0.1429 |
| 평균 절대 주차 오차 | 0.0242주 | 0.0232주 | 2.8248주 |

추가로 맞힌 것은 **한 장**이다. 기존 모델은 그 사진을 2주차로,
추가 학습 모델은 제공 라벨과 같은 3주차로 예측했다.
큰 성능 향상이나 통계적으로 유의한 개선으로 해석하지 않는다.
예측 CSV에서 일치율·주차 오차·혼동행렬을 독립 재계산해 보고서와 대조했다.

## 전체 점수보다 중요한 실패 사례

추가 학습 모델의 남은 불일치 8장은 모두 다음 조건이다.

- 촬영일: 2024년 8월 3일
- 제공 라벨: 1주차
- 예측: 4주차
- 1주차 시험 사진 19장 중 맞힌 사진: 11장
- 따라서 **1주차 재현율은 57.89%**다.

직접 사진을 비교했을 때, 이 묶음은 학습에 쓰인 1주차 사진과 화분·배경·촬영
구성이 달랐다. 같은 날짜의 4주차 사진과 유사한 촬영 구성이 보였다.
이것만으로 라벨 오류, 같은 식물, 실제 생육 주차를 확정할 수는 없다.
모델의 배경 의존, 촬영 분포 차이, 라벨·기록 문제 모두 확인이 필요하다.

따라서 이 8장은 **사람이 확인할 라벨 검수 후보**로 보관한다.
자동으로 4주차로 보정하거나 시험 자료를 다시 학습에 넣지 않는다.
원래 모델과 추가 학습 모델은 같은 가중치 출처이므로 둘의 동의를 독립적인
두 근거로 세지도 않는다.

## 해석 범위

1. 기존 모델도 같은 AI Hub 데이터셋에서 왔다. 원래 학습 분할이 알려져 있지
   않아 이번 시험 사진을 사전학습에서 이미 봤을 가능성을 배제할 수 없다.
2. 식물·화분·재배 회차 고유 ID가 없어 촬영일 분리가 식물 단위 독립성을
   보장하지 않는다. 배경·촬영자·화질 코드와 주차의 연관도 있다.
3. 9~11주차가 없고 초기 주차 자료가 적다. 14개 출력층을 유지했다는 이유로
   전체 14개 주차 성능을 검증했다고 말할 수 없다.
4. 이번에는 라벨을 정정하지 않았다. 따라서 이 비교는 **데이터 검수 전후
   성능 개선 실험이 아니라 기존 모델의 추가 학습 실험**이다.

## 개발자·데이터 담당자 관점의 활용

이번 결과에서 활용할 것은 높은 전체 점수 자체보다 다음 산출물이다.

- 원본 해시와 촬영일 분할이 고정된 학습 자료 목록
- 주차별 부족·편중 및 평가 범위 보고서
- 사람이 확인할 불일치 후보와 근거
- 기존 모델·추가 학습 모델·단순 기준 모델의 재현 가능한 비교
- 같은 형식으로 다시 불러올 수 있는 학습 가중치

추가 학습 모델은 별도 **실험용** AIStream 모델·서빙으로 배포 대상으로 삼는다.
기존 공용 모델과 공개 팜체크의 기본 모델 주소는 교체하지 않는다.
후속 성능 검증에는 독립적으로 수집·확인한 시험 자료가 필요하다.

현재 배포 대상은 **12팀 `WS-e06ca2ec`**이다. 권한 추가 후 실제 접근을 확인했고,
`Team12-FarmCheck-GreenTea-WeekQA-Pilot-v1` 등록 모델을 생성했다.
등록 모델은 `RM-2b7746fd` / `model-1c4cc046`이며 버전 1·2가 있다.
이미 실행된 워크플로 `WF-f2b10245`와 서빙 `SV-9e5ca608`을 확인했다.
현재 서빙은 모델 버전 1에 연결돼 있다. 에이전트가 이 워크플로를 새로 실행한 것은 아니다.

2026년 11월 7일 실제 서빙의 `/health`에서 HTTP 200과 `ready`를 확인했다.
기존 모델이 2주차, 추가 학습 모델이 3주차로 예측한 사진을 `/predict`에 전송했고,
HTTP 200, 3주차, 모델 신뢰도 0.641636을 받았다. 응답 헤더까지 약 1.02초였으며
이는 한 번의 연결 확인이지 지연 시간 벤치마크는 아니다.
API 기본 주소는 `https://aiopen-serving.jntp-ax.or.kr/jntp-cpu/SV-9e5ca608`이다.

등록 버전 2는 실제 다운로드한 10개 파일 모두 로컬 학습 번들과 해시가 일치했다.
서빙 중인 버전 1은 선택 사진의 추론 결과 일치만 확인했으며 파일 해시는 아직 대조하지 않았다.
버전 1·2의 파일 동일성을 주장하지 않는다.
교육용 `WS-eb575ae3`에서 진행했던 등록 시도를 12팀 배포로 집계하지 않는다.
GPU 서버에서 완료한 학습·평가와 AIStream 워크스페이스 권한은 별개의 사항이다.

비공개 원본·가중치·개별 예측·비교 사진은 `artifacts/private/`에 보관한다.
공개 문서는 집계 결과와 한계만 담는다.
