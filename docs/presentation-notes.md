# 발표 노트

덱: `presentation/deck.pptx`, `presentation/deck.pdf` (12장). 슬라이드 미리보기 PNG는 `presentation/render/` 에 생성됩니다.

## 다시 만들기

```console
uv run --isolated --no-project --with "python-pptx>=1,<2" python scripts/build_presentation.py --pdf
```

`--isolated` 라서 프로젝트 `.venv` 를 건드리지 않습니다. `--pdf` 는 설치된 PowerPoint(Windows COM)로 PDF와 1600x900 PNG를 내보냅니다. PowerPoint가 없으면 `--pdf` 를 빼고 PPTX만 만듭니다.
그림은 도형으로 직접 그렸고, 실제 사진이나 외부 이미지는 쓰지 않습니다.

## 장별 요점

1. 표지. 하지 않는 일(진단, 처방, 원인 확정, 원본 수정)을 먼저 말합니다.
2. 문제. 발견에서 인수인계까지 다섯 단계 흐름.
3. 원천. 3,872쌍, 사진 380x380, 시각 차이 148건은 오류가 아님.
4. 33과 24. 사진 기록과 후보 묶음은 다른 단위이고, 둘 다 문제 횟수가 아님.
5. 두 상태 축. 검토함이면서 보류는 정상.
6. 같은 출처. 다시 말한 것은 새 근거가 아님.
7. 모델 연결. 5장 모두 HTTP 200. 일치는 정확도가 아님.
8. 모델 없이도 수동 경로가 끝까지 됨.
9. 스냅샷. 버전 확인, 고정 바이트, 미해결 질문 포함.
10. 개인정보와 공개 모드. 배포 주소와 저장소 주소는 확정 전.
11. AgentStream. 오늘은 꺼져 있고 내일 연동.
12. 근거 범위와 3조건 실험 계획 (`docs/evaluation-protocol.md`).
