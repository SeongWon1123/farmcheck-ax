# 실제 녹차와 실험 모델이 연결된 로컬 시연

2026년 11월 7일 검증. 현재 작업공간에 있던 업로드·모델 프로필 구현을 활용해
실제 녹차 원본 ZIP과 12팀 실험 모델을 로컬 서버에 연결했다.
새 모델을 학습하거나 공개 서버를 교체한 작업은 아니다.

## 접속과 재실행

현재 실행 주소: `http://127.0.0.1:8512/`

이 주소는 이 PC에서만 열린다. 다른 PC의 localhost나 기존 공개 시연 주소와 다르다.
현재 서버가 실행 중이면 다시 실행하지 말고 주소를 열면 된다.
서버를 종료한 뒤에는 `farmcheck` 폴더에서 다음 명령으로 다시 실행한다.

```powershell
.\run-green-tea.ps1
```

ZIP 위치나 포트를 바꿔야 한다면:

```powershell
.\run-green-tea.ps1 -SourceZip "C:\자료\Sample.zip" -Port 8512
```

프로젝트의 기존 `.venv`를 사용한다. 원본 ZIP의 기본 위치는
`$HOME/Downloads/Sample.zip`이다.
자료는 `green_tea`, 모델은 `pilot`, DB는
`artifacts/private/green-tea-connected.sqlite`로 고정한다.
실제 데이터 3,872건을 읽으며, 추론은 버튼을 누른 기록에 대해서만 실행한다.
검토와 보고서는 브라우저 쿠키별 작업공간에 저장된다.
다른 브라우저에서 열면 검증 때 만든 보류 상태나 보고서가 보이지 않는 것이 정상이다.

## 한 화면에서 시연하는 순서

1. 상단의 `녹차 로컬 검토` 표시를 확인한다.
2. `분류 모델 연결 확인`을 누른다.
   `12팀 녹차 실험 모델 · v1 · pilot`과 연결 확인 상태가 보여야 한다.
   AgentStream의 미연결 표시는 이 이미지 모델과 별개다.
3. 목록 범위를 **전체 기록**으로 바꾸고 아래 파일명으로 검색한다.

   ```text
   SP05_L_B05_G_F12_S2_240803_173200_SV_W06
   ```

4. 검색된 기록을 열어 실제 사진과 원본 주차 **1**을 확인한다.
5. `실험 AI로 사진 비교 실행`을 누른다.
   검증 실행에서는 실제 API가 녹차·**4주차**를 반환했다.
   화면에는 실행 모델, 버전, 실행 ID, 이미지 해시, 소요 시간이 함께 남았다.
6. `재검사` 탭에서 `현재 버전 재검사`를 누른다.
   **현재 적용값 1주 / AI 4주 / 기록 오류 확정 아님**이라는 비교를 확인한다.
   모델 응답 채택과 현재 값 재검사는 별개 단계다.
7. `보류` 탭에서 다음과 같이 저장한다.
   - 이유: `원본 1주차와 모델 4주차가 달라 독립 근거 확인이 필요함.`
   - 다음 조치: `재배 시작일과 촬영일 원본을 확인하고 근거를 첨부해 재검토.`
8. 목록에서 그 기록의 체크박스를 선택하고 `검수 보고서(고정본)`으로 이동한다.
9. `목록에서 체크한 기록 1건`을 선택해 고정본을 만든다.
10. JSON·CSV·HTML을 내려받아 미해결 상태, 다음 조치, 모델 출처가 담겼는지 확인한다.

원본 라벨은 자동으로 바뀌지 않는다. 검증 후에도 이 기록의 적용 주차는 1이었다.
해소하려면 실제 독립 근거가 필요하므로 이 시연은 보류 상태에서 끝낸다.

## 발표 멘트

> “실제 녹차 사진과 원본 기록을 열었습니다. 원본은 1주차인데 배포 모델은
> 4주차로 예측했습니다. 어느 쪽이 맞는지는 사진만으로 확정할 수 없습니다.
> 그래서 원본을 바꾸지 않고 재배 시작일과 촬영 기록을 확인하도록 보류합니다.
> 모델 버전과 검토 근거를 고정 보고서로 남겨 다음 담당자가 이어받을 수 있습니다.”

## 이번 실행에서 확인한 결과

- 전체 회귀 테스트 127개 통과, basedpyright 오류·경고 0, Ruff 통과.
- 로컬 원본 3,872건 로딩 및 `models:/model-1c4cc046/1` 선택 확인.
- UI 버튼 → 백엔드 → `SV-9e5ca608`의 실제 사진 추론 성공.
- 실제 불일치 한 건의 재검사 → 보류 → 선택 범위 보고서 생성.
- JSON·CSV·HTML 다운로드 HTTP 200, JSON에는 실제 모델 출처와 보류 조치 포함.
- 새로고침 후 원본 주차·추론 결과·보류 상태·저장된 보고서 복원.
- 데스크톱과 390px 모바일에서 실제 결과를 확인했고, 모바일 가로 넘침은 없었다.
- 비공개 화면 증거: `artifacts/private/connected-ui-qa/`.

화면의 `신뢰도 출력 (미보정)`은 현재 계약에서 **작물 분류 점수**다.
생육 주차가 맞을 확률로 설명하지 않는다.
모델과 라벨의 불일치는 검수 후보이며, 라벨 오류나 데이터 검수 효과의 입증은 아니다.

## 공개 범위와 다음 결정

이번 연결은 로컬에서 완료했다. 기존 공개 사이트는 이 작업에서 배포하지 않았다.
공개 반영 시에는 실제 원본 ZIP 전체를 공개 카탈로그로 올리는 대신,
검증된 코드와 서버 측 모델 프로필을 반영하고 사용자가 선택한 자료만
작업공간에 추가하는 범위를 별도로 결정해야 한다.

일괄 추론, 실제 8개 불일치의 자동 등록, 검토 후 재학습, AgentStream 질의는
이번 연결의 기능이 아니다. 추가 학습 없이도 위의 한 건 시연은 가능하다.
