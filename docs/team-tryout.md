# 팀원이 직접 써 보는 팜체크

공개 주소: https://devopen.jntp-ax.or.kr/i/SpPClk4QcdJwast1/

모델을 설치하거나 AIStream 관리 화면에 들어갈 필요 없이 위 주소를 열면 됩니다.
AIStream 모델은 팜체크 백엔드가 호출합니다. AgentStream은 이 시험과 별개입니다.
2026년 11월 7일 검수 흐름 개편 기준 안내입니다.

## 준비

- 일반 브라우저를 쓰고 테스트 중 쿠키를 지우지 마세요.
- 제공 `Sample.zip`에서 아래 두 파일을 이름 그대로 추출합니다.

```text
SP05_L_B05_G_F12_S2_240803_173200_SV_W06.jpg
SP05_L_B05_G_F12_S2_240803_173200_SV_W06.json
```

ZIP 안 위치:

```text
Sample/01.원천데이터/05.녹차/01.생장/01.사이드뷰/
Sample/02.라벨링데이터/05.녹차/01.생장/01.사이드뷰/
```

팀 내부에서 `artifacts/private/team-test-kit.zip`을 받아 풀어도 됩니다.
실제 파일은 공개 GitHub나 누구나 내려받는 링크에 올리지 않습니다.

## 클릭 순서

1. **내 실제 자료**를 엽니다. 처음엔 목록이 비어 있는 게 정상입니다.
2. JPEG와 JSON을 여러 개 한꺼번에 끌어다 놓거나 **파일 선택**을 누릅니다.
   이름이 같은 파일끼리 자동으로 짝이 맞춰지고, 짝이 없는 파일은 따로 표시됩니다.
3. **가져온 뒤 바로 AI 비교**는 기본으로 켜져 있습니다. 사진을 실험 모델로
   보내는 데 동의한다는 뜻입니다. 확인한 뒤 **N쌍 가져오기**를 누릅니다.
4. 각 기록에서 원본 주차와 AI 주차를 나란히 보고 **어느 쪽이 맞나요?**에 답합니다.
   - **원본이 맞음**: 비교 근거를 첨부해 해소로 기록합니다.
   - **AI가 맞음**: 원본 JSON은 그대로 두고 보정값을 남긴 뒤 해소합니다.
   - **모르겠음**: 촬영일, 재배 시작일, 사진 품질, 다른 담당자 확인 같은 사유를 골라 보류합니다.
   두 값이 같으면 **일치 확인** 버튼 하나만 나옵니다.
   pH처럼 함께 확인할 항목도 같은 화면에 표시됩니다.
5. 저장 전에 무엇이 기록되는지 한 줄로 보여 줍니다. 확인하고 **기록하기**를 누릅니다.
   되돌리기 기능은 없으니 이 확인 단계에서 꼭 살펴보세요.
6. 저장하면 다음 미판단 기록으로 넘어가고 진행률이 **N건 중 M건 판단**으로 바뀝니다.
   J/K 키로 이전·다음 기록을 오갈 수 있습니다.
7. 모두 판단하면 **이번 검수 보고서 받기**에서 HTML, CSV, JSON을 내려받습니다.
   저장된 보고서는 **보고서** 탭에서 다시 열 수 있습니다.

샘플의 기대 결과는 **원본 1주 / AI 4주(녹차)**입니다.
JSON 선언 해상도와 실제 JPEG 크기 차이 경고는 예상된 결과입니다.

값 보정, 검토 메모, 해소 근거 직접 선택, 원본 JSON, 해시, 변경 이력은 **상세 옵션**에 있습니다.
파일 없이 흐름만 보려면 왼쪽에서 **시연 예제**를 고르세요. 합성 자료라 실제 AI 호출은 없습니다.

## 알아 둘 것

- 브라우저마다 별도 작업공간이고 접근 수단은 쿠키입니다. 로그인·복구 기능은 없습니다.
  다른 브라우저나 시크릿 창에서 기록이 안 보이는 건 정상입니다.
- 다른 팀원의 판단은 자동 공유되지 않습니다. 보고서 파일로 주고받으세요.
- 원본과 AI가 다르면 재확인 후보일 뿐, 라벨 오류로 확정된 게 아닙니다.
- 분류 점수는 모델 출력값이며 정답일 확률이 아닙니다.
- **원본 환경 기록**의 pH·온도는 JSON 값입니다. AI가 사진에서 잰 값이 아닙니다.
- 대회 자원과 URL은 행사 종료 후 회수될 수 있습니다.

## 문제가 생겼을 때

- 짝이 안 맞음: 두 파일 이름이 확장자만 빼고 같은지 확인합니다.
- 중복 가져오기: 이미 있는 기록을 목록에서 찾아 이어서 판단합니다.
- 모델 연결 실패: 원본은 그대로 남습니다. 비교 영역의 다시 시도를 누르고 오류 문구를 기록합니다.
- 버전 충돌: 기록을 다시 연 뒤 최신 내용을 보고 다시 저장합니다.
- 검사 갱신만 실패: AI 결과와 판단은 남아 있습니다. 새로고침 후 기록을 다시 열어 봅니다.

피드백에는 기기·브라우저, 단계 번호, 기대한 결과, 실제 메시지를 적어 주세요.
화면 공유 때 쿠키·인증 정보와 불필요한 실제 원문은 빼 주세요.
