# 결과 의미와 검수 흐름 개편

2026년 11월 7일. 사용자가 결과 오류와 사용 흐름을 함께 수정하는 범위를 선택했다.
수정 도중 이미 반영되어 있던 workbench-v2 화면은 보존하고 그 위에 필요한 변경을 연결했다.
그 화면 전체를 이번 작업에서 새로 작성한 것으로 설명하지 않는다.

## 변경

- 실제 자료와 합성·주입 시연을 별도 범위로 조회·집계한다. 기본은 실제 자료다.
- 원본 사진과 현재 기록/AI 주차를 비교 영역에서 보여준다.
- pH·EC·온도 등은 AI 측정 결과가 아닌 원본 JSON 기록임을 명시하고 상세로 분리한다.
- 작물·주차 분류 점수를 구분한다. 과거 결과에 없던 주차 점수는 생성하지 않는다.
- 최근 재시도 실패와 이전에 채택한 성공 결과를 별도로 보여준다.
- 서버의 정확한 주차 비교를 사용하며, 다른 기록 비교는 동일 작물 조건도 확인한다.
- 연결 상태는 자동 확인하지만 사진 추론은 사용자가 직접 실행한다.
- 추론·보정 뒤 규칙 검사만 순차 갱신한다. 검토·보류·해소 판단은 자동 저장하지 않는다.
- 현재 기록 1건 또는 체크한 기록만 보고서를 만든다. 전체 후보 자동 포함을 제거했다.
- 원본/해석/적용값, 단위 출처, 원본 JSON, 해시, 이력과 기존 판단 기능은 펼치기에 보존했다.
- 잘못된 입력, 409 충돌, 초안 보존, 최신 내용 복구의 상태와 포커스를 확인했다.

## 공개 반영 범위

서버 점검 시 수정된 백엔드 4개 파일은 이미 로컬과 SHA-256이 일치했다.
이번 반영 패키지는 정적 화면 3개 파일(index.html, app.js, style.css)만 포함한다.
원본 ZIP, 사진, DB, 인증키, 모델 가중치는 패키지에 없다.
정적 파일을 요청 시 읽는 구조이므로 해당 화면 반영에 앱 재시작은 필요하지 않다.
