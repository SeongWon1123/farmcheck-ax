# 화면 배치와 검증 계약

Layout: 기록 목록 + 상세 / document가 상세의 세로 스크롤 소유자.
데스크톱 목록은 sticky `.list-pane` 안의 `.list-body`가 독립 목록 스크롤을
소유한다. 1023px 이하에서는 목록 또는 상세 한쪽만 표시하고 뒤로 가기로 이동한다.
표는 `.tbl-wrap` 안에서만 가로 스크롤하며 문서 전체를 가로로 밀지 않는다.
원문 JSON 접기는 `.json` 내부의 제한된 스크롤이다.

주요 행동: 확인할 기록을 고른 뒤 원문과 적용값을 비교하고 사람의 판단을 남기는 것.
정보 순서: 현재 상태와 확인 이유, 사진·원문·적용값, 사람의 조작,
필요할 때 펼치는 출처·비교·변경 이력. 사진의 좌표나 크기를 보정하는 요소는 없다.

탐색의 숫자는 필터 선택과 연결한다. 처음에는 기록 선택 방법과 다음 행동을
안내한다. 짧은 표시 ID는 전체 ID를 지우는 것이 아니며, 명시적인 펼치기에서
전체 식별자를 확인한다. 비교 표는 숫자와 짧은 ID를 한 줄로 유지하고
기술 필드명은 pH·EC·CO2·온도·습도로 표시한다.

값 표는 항목 / 원문·해석 / 적용값 / 단위·출처의 네 열이다.
모바일에서는 같은 정보를 행 단위의 두 열로 재배치한다.
적용값의 파싱 상태를 원문의 상태처럼 표시하지 않는다.
키 없음·null·공백·대시·0·해석 불가를 서로 다른 표시로 유지한다.

인수인계와 규칙·AgentStream은 한 열 문서 흐름이다. 작성된 문서를 숨기거나
미해결을 접어 수를 줄이지 않는다. 표의 숫자는 읽을 폭을 유지하며 작은
화면에서는 표 영역에서 가로로 이동한다. 390px와1440px의 실제 렌더링으로 검증한다.

검토 행동은 검토 / 보류 / 보정 / 재검사 / 해소 탭에서 하나씩 표시한다.
탭은 방향키와 Home/End로 이동하며 저장 중에는 같은 기록의 입력을 잠근다.
필수 입력 오류는 입력 바로 아래에 표시하고 첫 오류로 포커스를 옮긴다.
초안은 기록과 행동별로 현재 탭 메모리에 보관하며 새로고침 후 보존을 약속하지 않는다.
충돌이나 결과 불명 응답에서는 초안을 유지한 채 최신 기록을 다시 불러온다.
늦게 도착한 응답은 사용자가 새로 선택한 기록이나 그 초안을 바꾸지 않는다.

인수인계의 주요 행동은 포함 범위를 확인하고 현재 내용의 고정본을 저장하는 것이다.
범위는 설명을 함께 읽을 수 있는 라디오 선택이며 화면을 오가도 유지된다.
저장 결과로 포커스를 옮기고 JSON / CSV / HTML의 용도를 안내한다.
작업공간이 이후 변경되면 기존 다운로드는 저장 당시 내용임을 표시한다.
긴 식별자는 펼치기로 보존하고, 이력의 메모·이유·다음 조치는 별도 항목으로 표시한다.
AI 질의는 연동 예정으로 안내하며 상대 날짜나 작동하지 않는 질문 입력은 제시하지 않는다.
