# 화면 배치와 검증 계약

Layout: 기록 목록 + 상세 / document가 상세의 세로 스크롤 소유자.
데스크톱 목록은 sticky `.list-pane` 안의 `.list-body`가 독립 목록 스크롤을
소유한다. 1023px 이하에서는 목록 또는 상세 한쪽만 표시하고 뒤로 가기로 이동한다.
표는 `.tbl-wrap` 안에서만 가로 스크롤하며 문서 전체를 가로로 밀지 않는다.
원문 JSON 접기는 `.json` 내부의 제한된 스크롤이다.

주요 행동: 후보를 고른 뒤 사람이 검토·보류 사유를 남기는 것.
정보 순서: 현재 사람 상태, 후보로 잡힌 이유, 사진과 원문/적용값, 출처와 비교,
사람의 조작 및 이력. 원본 사진의 좌표나 크기를 보정하는 시각 요소는 두지 않는다.

인수인계와 규칙·AgentStream은 한 열 문서 흐름이다. 작성된 문서를 숨기거나
미해결을 접어 수를 줄이지 않는다. 표의 숫자는 읽을 폭을 유지하며 작은
화면에서는 표 영역에서 가로로 이동한다. 390px와1440px의 실제 렌더링으로 검증한다.
