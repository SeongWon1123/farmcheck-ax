# 사진 확인 권장 경고 평가

평가일: 2026-11-07. 선택적 검토 보조 기능이며 라벨 오류 판정이나 자동 보정이 아니다.
구현 파일은 `src/farmcheck/static/quality.js`이고 UI 연결은 별도 작업이다.

## 표본과 계산

- 제공된 `Sample.zip`의 녹차 JPG 3,872장 중 `random.Random(20261107)`로
  400장을 비복원 추출했다. 원본마다 Gaussian blur 반경 1.5/3/5,
  밝기 ×0.35/×1.8, 대비 ×0.2를 PIL로 적용했다. 총 2,800회 측정했다.
- 대비 변환은 `ImageEnhance.Contrast(...).enhance(0.2)`,
  밝기는 `ImageEnhance.Brightness`이다. 변형 후 JPEG 재압축 없이 측정했다.
- RGB를 `floor((299R + 587G + 114B + 500) / 1000)`의 정수 명도로 변환한다.
  brightness는 전체 픽셀 평균, contrast는 전체 픽셀 모집단 표준편차다.
  sharpness는 중앙 -4, 상하좌우 +1, 대각선 0인 3×3 Laplacian의 모집단
  분산이다. 가장자리 1픽셀은 Laplacian 계산에서 제외한다.
- 브라우저는 종횡비를 유지해 긴 변을 최대 380px로 줄인 canvas에서 계산한다.
  원본 표본은 모두 380×380이라 이번 평가는 리샘플러 차이를 포함하지 않는다.
  3px 미만 변이 있어 내부 픽셀이 없으면 sharpness는 0이다.

## 작물 모델 실측

제공된 `SV-9e5ca608` 서비스에 multipart `file`로 순차 요청했다.
비녹차 작물별 10장, 녹차 20장, 스트레스 이미지 2장으로 **추론 102회**를
완료했으며 모두 HTTP 200이었다. 평가 스크립트는 health 포함 103회,
별도 사전 health 조회를 포함해도 최대 104회로 150회 이내다.
429는 발생하지 않았다. 스크립트는 429 발생 시 `Retry-After`를 준수한다.
추론 지연시간은 최소 394ms, 중앙 491ms, 최대 1,466ms였다.

| 원래 작물 | 표본 | 같은 작물 예측 | 녹차 예측 |
|---|---:|---:|---:|
| 밀순 | 10 | 10 | 0 |
| 새싹인삼_개량종 | 10 | 10 | 0 |
| 새싹인삼_연풍 | 10 | 10 | 0 |
| 양상추 | 10 | 10 | 0 |
| 녹차 | 20 | 20 | 20 |
| 두메부추 | 10 | 10 | 0 |
| 팥순 | 10 | 10 | 0 |
| 구절초_넓은잎 | 10 | 10 | 0 |
| 구절초_좁은잎 | 10 | 10 | 0 |

비녹차→녹차 혼동은 **0/80 (0%)**다. 따라서 이 표본에서 CROP_NOT_TEA는
비녹차 80/80건에 표시되고 녹차 원본에는 0/20건 표시된다.

| 원본 집단 | crop confidence 최소 | 중앙값 | 최대 |
|---|---:|---:|---:|
| 녹차 20장 | 1.000000 | 1.000000 | 1.000000 |
| 비녹차 80장 | 0.999498 | 1.000000 | 1.000000 |

비녹차 중 밀순 최솟값은 0.999988, 구절초_넓은잎은 0.999498이며
나머지 여섯 작물은 모두 1.000000이었다. 표는 API가 반환한 정밀도 그대로다.
신뢰도만으로 녹차와 비녹차를 구분할 수 없으므로 **예측 작물명 비교가 우선**이다.

| 스트레스 입력 | 예측 작물 / 신뢰도 | 예측 생장주차 / 신뢰도 |
|---|---|---|
| 식물이 없는 회색 수평 그라디언트 JPEG | 새싹인삼_개량종 / 0.699493 | 0주차 / 0.787170 |
| 녹차 Gaussian blur 반경 5, JPEG 저장 | 새싹인삼_개량종 / 0.682859 | 5주차 / 0.933002 |

모델은 비식물에도 작물과 주차를 반환했다. 이를 비식물 검출기로 사용하면 안 된다.
`CROP_LOW_CONFIDENCE`는 **녹차 예측이면서 confidence < 0.8**일 때만 표시한다.
0.8은 원본 녹차 20장의 1.0보다 낮고 스트레스 입력 두 건의 약 0.68~0.70보다
높은 보수적 시연 기준이다. 원본 녹차 경고는 0/20건이다.
두 스트레스 입력은 녹차로 예측되지 않았으므로 CROP_NOT_TEA가 적용되며,
낮은 신뢰도 녹차 표본에 대한 실제 검출률은 **미측정**이다.
0.8을 최적화된 통계적 경계나 라벨 오류 확률로 주장하지 않는다.

## JS/Python 일치와 실행 검증

- 12장에 대해 PIL 디코딩 RGB 바이트와 Python 기준값을 private 경로에 저장했다.
  Bun의 VM에서 실제 배포할 `quality.js`를 실행하고 canvas 입출력만 같은
  RGB 픽셀로 대체했다. 세 지표 모두 절대 오차 < 1e-9 조건을 통과했다.

  세 지표 최대 절대 오차는 **0**, 두 브라우저 입력 형식의 결과도 동일했다.
- 760×570 단색 사진의 실제 브라우저 측정은 sharpness 0 / brightness 128 /
  contrast 0이었고 BLURRY, LOW_CONTRAST를 반환했다.

- `bun test artifacts/private/quality-eval/quality.test.js`:

  새 패키지를 설치하지 않았다. 연결 전 독립 스크립트이므로 전체 UI 통합은 별도 검증 대상이다.

## UI 연결 계약

`quality.js`를 `app.js`보다 먼저 로드한다.
가져오기 미리보기의 사진 decode/load 완료 시와 상세 사진 load 완료 시
`FarmQuality.measure(img)`를 호출한다. 가져오기 미리보기에는 모델 없이
`FarmQuality.assess(metrics)`를 호출한다. 새 사진으로 바뀌면 이전 경고를 제거한다.
사진이 같은 경우 모델 결과를 받았을 때 기존 metrics로 assess만 다시 호출한다.
빠르게 사진을 전환할 때 이전 load 완료 결과를 새 사진에 붙이지 않도록 출처를 확인한다.

```js
const metrics = window.FarmQuality.measure(img);
// detail.model은 평탄화된 앱 계약이므로 원본 모델 API 형식으로 변환한다.
const modelResult = detail.model?.status === "ok"
  ? { crop: {
      name_ko: detail.model.crop,
      confidence: detail.model.crop_confidence ?? detail.model.confidence,
    } }
  : undefined;
const warnings = window.FarmQuality.assess(metrics, modelResult);
```

반환값은 `{code, level, message_ko, value, threshold}[]`다.
사진 지표 네 종류는 `warn`, 작물 관련 두 종류는 `info`다.
판단 패널에 별도의 **사진 확인 권장** 영역을 두고 `message_ko`를 textContent로
표시한다. 원래 규칙 결과, 선택한 검토 결정, JSON 라벨을 변경하거나 완료를 차단하지 않는다.
측정 실패 시 해당 사진은 평가 불가로 표시하고 정상 판정이나 0점으로 대체하지 않는다.
입력 사진은 정상 디코딩된 동일 출처 이미지/로컬 객체 URL이어야 한다.
서로 다른 출처의 CORS 미허용 이미지에는 canvas 보안 예외가 발생할 수 있다.

## AgentStream 보류와 한계

사용자 결정으로 AgentStream 요청과 이미지 전송은 수행하지 않았다.
향후 제공할 항목은 **API key, base URL, 인증 헤더 이름과 값 형식,
workspace UUID, chatbot UUID, 요청 schema**다. 직접 모델 호출을 쓰는 계약이면
**model name**도 필요하다. 교육 자료는 공개 챗봇과 API 권한 매핑 및
연동 가이드 복사를 안내하지만 구체적인 요청 경로/본문은 그 가이드가 필요하다.
이미지 입력 지원과 지연시간은 검증하지 않았다.

동일 출처 자료의 380px 축소 사진과 인위적 변형에 대한 평가다.
새 농장·촬영기기·조명·해상도의 현장 검증이 아니며, 원본 품질의 사람 정답도 없다.
같은 표본으로 임계값을 선택했으므로 일반화된 오탐률 보장이 아니다.
평균 명도와 대비는 국소 과노출, 가림, 병해, 잘못된 구도나 라벨 오류를 검출하지 못한다.
파일 책임은 사진 지표와 검토 힌트 생성 하나이며 외부 통신이나 상태 변경이 없다.
타입 우회, 불필요한 방어 계층, 일회성 추상화와 새 로깅은 추가하지 않았다.
